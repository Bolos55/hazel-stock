## 🎯 System Overview

This is a **Daily Stock Recording System** where employees:
1. Take photos of remaining stock
2. Input quantities using simple +/- buttons
3. Submit once daily (data locked after submission)
4. Excel auto-generates at 23:55 every night

## 🚀 How to Use

### For You (Setup)
1. Upload files to server
2. Run `composer install` for PhpSpreadsheet
3. Import `database.sql`
4. Edit `config.php` with database credentials
5. Setup cron job: `55 23 * * * php /path/to/cron/daily-excel-export.php`
6. Done!

### For Employees (Daily Use)
1. Open app on phone
2. Enter name
3. Adjust quantities with +/-
4. Take photos for each item
5. Submit when progress bar is 100%

### Excel Files
- Auto-generated at 23:55 every night
- Saved to `excel-exports/stock_YYYY-MM-DD.xlsx`
- Contains all data + clickable photo links
- Thai formatting, professional appearance
